# Inventory Management System

A Java-based desktop Inventory Management System designed to simplify and organize day-to-day inventory operations.

The system provides a centralized interface for managing products, current stock, customers, suppliers, purchase orders, sales orders, user accounts, and audit logs.

---

## Overview

The Inventory Management System provides a structured solution for managing inventory and business transactions through a desktop application.

The application includes role-based access, product management, customer and supplier management, sales and purchase processing, stock monitoring, and audit logging.

The system is designed with a clean and modern dark-themed user interface to make inventory operations easier to navigate and manage.

---

## Features

### 🔐 User Authentication

- Secure login interface
- Username and password authentication
- User role selection
- Administrator and employee access
- Sign-out functionality

### 📊 Dashboard

The dashboard provides an overview of the inventory system, including:

- Total products
- Total suppliers
- Total customers
- Sales records
- System status
- Quick navigation
- System information and tips

### 📦 Product Management

Users can manage the product catalog through:

- Add products
- Update products
- Delete products
- Product codes
- Product names
- Supplier information
- Date received
- Quantity
- Cost price
- Selling price
- Brand/manufacturer
- Product search

### 📈 Current Stock

The system provides current inventory information for monitoring available stock quantities and identifying stock-related information.

### 👥 Customer Management

Customer records can be maintained using:

- Customer code
- Full name
- Location / city
- Contact / mobile number
- Debit amount
- Credit amount
- Add customer
- Update customer
- Delete customer
- Customer search

### 🚚 Supplier Management

Supplier information can be maintained and associated with products and purchase transactions.

### 🛒 Purchase Orders

The purchase module allows inventory purchases to be recorded and managed through supplier and product information.

### 💰 Sales Orders

The sales module supports:

- Customer selection
- Product selection
- Order date
- Unit price
- Quantity to sell
- Sales processing
- Revenue calculation
- Sales transaction history

### 👤 User Accounts

The system supports management of application users and their access roles.

### 📋 Audit Logs

System activity can be tracked through audit logs, including user-related actions and login/sign-out activity.
